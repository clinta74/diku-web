## Quick Start

1. **Create .env from template:**
   ```bash
   cp .env.example .env
   # Edit .env with your configuration
   ```

2. **Deploy:**
   ```bash
   docker-compose pull
   docker-compose up -d
   ```

3. **Verify:**
   ```bash
   docker-compose ps
   docker-compose logs web
   ```

## Security Notes

- POSTGRES_PASSWORD must be changed in production
- Use strong passwords for database
- Restrict database port to localhost (127.0.0.1:5432)
- Adminer should be disabled in production
- Use reverse proxy for HTTPS (not HTTP)
- Keep secrets in .env (add to .gitignore)
- Regular backups essential for data safety
